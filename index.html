Evolution settings

Settings apply together on restart. The best 3 cars survive each generation unchanged; the rest are bred with random mutations.

Simulation controls

Save/load uses only this browser. A saved brain keeps its original circuit. Refresh starts fresh random cars. Training pauses when this tab is hidden.

How the cars actually learn

Each car reads five distances to the road edge and its own speed. A tiny neural network (6 inputs, 8 hidden units, 2 outputs) chooses steering and throttle. There is no scripted driver. Cars that crash or stop making forward progress are eliminated. Fitness rewards forward circuit distance, completed laps and faster lap times. At each generation boundary, tournament selection chooses parents, crossover mixes their weights, and mutation changes a fraction of weights. The best three brains are preserved. Performance can plateau; a new population or a higher mutation rate can explore new solutions. Lap times and generation duration use simulation time, not wall-clock time. Speed is a target, so slower phones may run below it.
